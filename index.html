Personal Health Dashboard — Privacy Policy

Last updated: 9 November 2026

This is a personal integration intended for the account owner to view their own WHOOP data in a locally operated health dashboard. It is not offered as a public service.

Data and purpose

With the account owner's authorization, the integration is intended to read sleep, recovery, physiological cycle and workout information from the WHOOP API. These records are used to display personal health and activity trends in the dashboard. Only permissions needed for these purposes should be requested.

Storage and sharing

The synchronization program is intended to run on the owner's computer and store its settings, authorization tokens and imported data locally. The public repository that hosts this policy is not intended to contain personal health records, authorization codes, tokens or application secrets. WHOOP processes data according to its own policies. The owner controls any additional copies, backups or services they choose to use.

The authorization callback is hosted on GitHub Pages and forwards the short-lived authorization response to a local service on the owner's computer. The response passes through the browser and GitHub Pages infrastructure; GitHub may process request metadata under its own policies. The public callback page does not itself store tokens or health records.

Access and deletion

The owner may revoke the integration's access through WHOOP and remove locally stored credentials and imported data. Revoking access stops new authorized retrievals but does not automatically delete data already saved locally. The owner can request assistance via the repository's GitHub issue tracker; please do not post health details or credentials there.

Contact

Contact the account owner through the issue tracker of the repository hosting this policy.
